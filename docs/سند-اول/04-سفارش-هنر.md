# سفارش هنر — مرجع سبک جدید (بخش د سند اول، ۱۹ سپتامبر ۲۰۲۶)

کارفرما پنج تصویر مرجع داد (پوشه‌ی `04-مرجع-سبک/`): کمپ‌های نقاشی‌شده‌ی واقع‌گرا، سرزمین گنج با مرکز گداخته، نقشه‌ی حلقه‌ای (چمن سبز بیرون → کوهستان → حلقه‌ی تاریک جهنمی → مرکز طلایی گنج)، کاشی‌های ایزومتریک چمن و علف خشک. **این سبک (نقاشی دیجیتال واقع‌گرا، نور گرم، بافت غنی) از این پس هدف بصری بازی است** و جای هنر وکتوری اصلاحیه‌ی ۳ را می‌گیرد، به‌محض این‌که دارایی‌های زیر تحویل شوند.

موتور بازی آماده‌ی پذیرش این دارایی‌هاست:
- **بافت زمین**: فایل‌ها را در `public/assets/textures/` بگذارید و `index.json` بنویسید؛ شیدر زمین (`src/render/ground.ts`) خودکار به‌جای بافت رویه‌ای از آن‌ها استفاده می‌کند و مرزهای موج‌دار و نور و شبکه‌ی محو را رویشان نگه می‌دارد.
- **اسپرایت‌ها**: PNG شفاف در `public/assets/sprites/<گروه>/` با همان نام‌های `manifest.json` جایگزین می‌شوند (نیاز به بازسازی نیست؛ فقط `npm run build`).

| `cracked` | سرزمین خطر | seamless tileable top-down texture of dry cracked red-brown earth with ash and scorched patches, painterly realistic game texture, even lighting, 1024x1024 |
| `lava` | جهنمی | seamless tileable top-down texture of black volcanic rock with glowing orange lava cracks and embers, painterly realistic game texture, 1024x1024 |
| `stone` | مقبره | seamless tileable top-down texture of ancient dark purple-grey stone pavement with carved runes, painterly realistic game texture, 1024x1024 |

| `chasm` | دره | seamless tileable top-down texture of a deep dark rocky chasm floor, near-black with faint rock edges, painterly realistic game texture, 1024x1024 |

`public/assets/textures/index.json`:
```json
{ "grass": "grass.jpg", "dry": "dry.jpg", "rock": "rock.jpg", "marsh": "marsh.jpg", "cracked": "cracked.jpg", "lava": "lava.jpg", "stone": "stone.jpg", "gold": "gold.jpg", "chasm": "chasm.jpg" }
```
نکته: به ابزار بگویید «seamless tileable» و «no objects, no shadows»؛ اگر لبه‌ها درز داشتند، همان ابزار یا فتوشاپ (Offset + Heal) درز را می‌گیرد. مقیاس در بازی: هر بافت روی ۴×۴ خانه تکرار می‌شود.
