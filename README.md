# بازی گنج (Ganjgame)

بازی نقشه‌محور و فصلی روی نقشه‌ی ۱۰۰۰×۱۰۰۰ خانه، با نمای سه‌بعدی low-poly استایلایز (دیورامای کج‌شده). قوانین بازی و هدف بصری از **سند اول** می‌آیند:

- `docs/سند-اول/Ganjgame.docx` و متن استخراج‌شده‌اش `docs/سند-اول/01-منطق-بازی-و-چک‌لیست-قوانین.md`
- `docs/سند-اول/02-هدف-بصری.md`

`CLAUDE.md` این دو را به‌عنوان قانون پروژه ثبت کرده است.

## اجرا

```bash
npm install
npm run dev        # http://localhost:5173  (بازی)  ·  /admin.html (پنل ادمین)  ·  /faq.html (سوالات پرتکرار)
npm test           # تست‌های قوانین (vitest)
npm run build      # خروجی تولید در dist/
npm run assets <مسیر Stylized Nature MegaKit>/glTF   # بازسازی GLBها از منبع
```

## ساختار

| مسیر | نقش |
|---|---|
| `src/rules/constants.ts` | همه‌ی اعداد پایه‌ی سند اول (تدارکات، موجودات، نیروها، تجربه، جایزه‌ها…) |
| `src/rules/settings.ts` | تنظیمات قابل ویرایش ادمین + اعتبارسنجی (مقادیر مخرب با دلیل رد می‌شوند) |
| `src/rules/terrain.ts` | مولد قطعی زمین: ۱۰ نقشه، تابیدن دامنه، هسته‌ی خطر شیبدار، سرزمین جهنمی، دره‌های رگه‌ای (≤۳۰ خانه) |
| `src/rules/combat.ts` | قدرت لشگر، وزن انرژی، برتری زمین، فرمول تلفات، تجربه، اشیای پیداشده |
| `src/rules/level.ts` | منحنی سطح (۱۲۰ × ۱٫۵؛ سطح ۵=۹۷۵، ۷=۲٬۴۹۵، ۱۰=۸٬۹۹۳) |
| `src/rules/tombs.ts`، `camp.ts`، `path.ts`، `economy.ts` | مقبره‌ها، کمپ اولیه، کم‌هزینه‌ترین راه، ارزش جایزه‌ها |
| `src/rules/state.ts` | وضعیت بازی و همه‌ی کنش‌ها (خرید، کوچ، جنگ، تصاحب، آرتیفکت، گنج، پایان فصل، کلن، کیف پول)، امضا و سخت‌گیری |
| `src/render/` | Three.js: زمین مش flat-shaded با رنگ رأس، صحنه‌آرایی Instanced از مدل‌های Quaternius، خورشید ۳۵° با سایه، دوربین ثابت ۵۵°/fov 30، بلوم/وینیت/گرید |
| `src/ui/app.ts` | رابط فارسی راست‌به‌چپ: هدر، تب‌ها، کارت خانه، نمای کل سرزمین، مودال نام و آموزش |
| `src/admin.ts` + `admin.html` | پنل ادمین شش‌تبه (وضعیت و امنیت · فصل و نقشه · اعداد · پرونده‌ی بازیکن · پشتیبانی · تنظیمات ذخیره‌شده) |
| `faq.html` | ۲۶ پرسش در ۷ دسته |
| `public/assets/models/` | ۳۱ مدل CC0 از «Quaternius — Stylized Nature MegaKit» (GLB فشرده، بافت WebP ۲۵۶px) |
| `tests/` | تست‌های زمین، قوانین، وضعیت |

## کلیدهای ذخیره‌سازی (localStorage)

`ganj-final-v1` وضعیت بازی · `ganj-admin-v1` تنظیمات · `ganj-admin-cmd-v1` فرمان آغاز فصل · `ganj-support-v1` تیکت‌ها · `ganj-season-v1` نشان فصل · `ganj-final-lock-v1` قفل ساعت بازی.

## وضعیت پیاده‌سازی نسبت به چک‌لیست سند اول

پیاده‌شده: نقشه و زمین (بند ۱، ۱۷)، سطح و دروازه‌ها (۲)، کوچ و تصاحب (۳: چسبیده، بلند تا ۲۰ خانه با پیش‌پرداخت و اعلام برخوردها، سفر رایگان، لغو، نگاهبان ارزان‌ترین، حداقل ۲ نیرو)، مقبره‌ها و آرتیفکت (۴)، گنج اصلی و پایان فصل (۵: کف ۲۰۰ میلیون / ۴۰٪، مشارکت ۱۰٪، گزارش گنج نهایی، ۲۴ ساعت واقعی، فروش خودکار آرتیفکت، واریز به شبا)، نیروها و تلفات (۶)، اقتصاد و کیف پول (۷)، کلن (۹–۱۱ در حد یک بازیکن واقعی: ساخت، خزانه‌ی فقط‌سکه، اهدای لحظه‌ای نیرو، سهم و وزن رأی، کمپ کلن، سوئیچ به اکانت کلن، لاگ تفکیک‌شده)، ظرفیت فصل و نام (۱۳)، پنل ادمین و قفل فصل (۱۴)، قفل ساعت چند تبی و امضای وضعیت (۱۵)، بدون بازیکن مجازی (۱۲، ۱۶).

نیازمند سرور (در این نسخه‌ی تک‌کاربره‌ی مرورگری وجود ندارد): بازیکنان واقعی دیگر، قفل هم‌زمان کوچ بین بازیکنان، بازار آرتیفکت با پیشنهاد/بلوکه‌ی واقعی، عضویت چندنفره و انتخابات کلن، درگاه پرداخت و واریز واقعی به شبا (واریز و برداشت فعلاً در کیف پول شبیه‌سازی می‌شود).
